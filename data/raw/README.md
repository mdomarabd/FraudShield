# Raw Dataset

The raw dataset `creditcard.csv` (~150 MB) is excluded from version control to comply with GitHub file size limits (<100 MB).

You can download the dataset directly from Kaggle:
👉 **[Kaggle: Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)**

Place `creditcard.csv` in this directory:
```
data/raw/creditcard.csv
```
